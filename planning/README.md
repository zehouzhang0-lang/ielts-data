# 规划模块

规划板解决的是“今天做什么、做到什么算完成”，不替代各科成绩与错误记录。

## 当前策略

- 占位考试日：2026-10-15；日期尚未确认，倒计时只作估算。
- 每周预算：735 分钟（12 小时 15 分）。
- 周一至周五各 105 分钟，周六 180 分钟，周日 30 分钟复盘。
- 各阶段用独立周模板；把周日听读复盘计入后，听读占实际计划的 80.3%–82.5%。
- 词汇只清真实错题和逾期复习；4235 条导入词库是候选池，不是必须线性刷完的欠账。
- 打字嵌入写作训练；正确率已接近 100%，现阶段看 WPM。

## 两种进度

1. **执行进度（自报）**：完成时必须填写用时与结果摘要；V1 尚不自动核验各科记录。
2. **能力进度**：真题正确率、写作四维、口语可评维度和技巧 mastery 是否达到阶段门槛。

完成任务不自动等于达标。低于门槛但自报了完整结果和错因，仍记为完成，再由下一次计划安排修复；各科 submission 与技巧 mastery 才是能力证据。

## 数据文件

- `strategy.yaml`：阶段、预算、每周模板和任务目录。
- `days/YYYY-MM-DD.yaml`：当天首次变更状态时固定下来的计划快照。
- `events/*.yaml`：每次完成、跳过或重新打开的追加式事件。

不同设备只追加各自事件，避免同时修改一张清单。详细字段见仓库根目录 `SCHEMA.md`。

## 调度原则

- 每天最多 4 项，分钟数不超过当天预算。
- 当天至少有一个主弱项、一个真题/错题验证动作和一个可在有限时间内验收的产出。
- 前一天欠账最多滚入一个 `must`，禁止形成无限任务债。
- 课程只能安排为“定位片段 → 摘要 → 真题验证 → adopted/rejected”，播放完不计完成。
- 听力任务必须先确认本机有合法音频；当前只核验了 `D:\IELTS\` 的剑15 Test 1–4。无音频或没有未使用套题时标记跳过并记录素材缺口，禁止拿转录假装听力、也禁止把重做分数计作新基线。
- 每周复盘比较计划完成量与能力门槛；两次连续未达标时，下一周从稳定科目转 30–45 分钟给瓶颈。
