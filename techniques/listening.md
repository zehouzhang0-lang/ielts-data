# 听力题型技巧卡

> 用户现状：L6.0 → 目标 7.5。Section 4 note completion 只对 3/10，是最大失分点。
> 推荐配套：B站「Sun 老师教雅思」听力技巧、「Cora」地图题（见 [_source-xhs-6.5.md](_source-xhs-6.5.md)）

## 通用铁律（所有题型通用）

1. **读题时间用来划关键词**，不是发呆。划的是：名词、数字、限定词（only/most/first）
2. **预判答案词性**：空格前是 `the` → 填名词；前面是 `to` → 填动词原形。预判错了就知道听错了
3. **听到就写，不要等**。雅思听力答案按顺序出现，几乎不倒序
4. **一题没听到立刻放弃**，眼睛移到下一题。纠结一题 = 丢一串（用户已犯过：S2 连错 4 题）
5. **注意信号词**：`but / however / actually / in fact / sorry` 后面往往是答案修正——前面说的是陷阱

## Note / Form / Table Completion（用户 S4 主要失分处）

### 核心技巧
- 空格前后各读 3-5 个词，**这些词会以同义替换形式在音频里出现**
- 严格遵守字数限制（`NO MORE THAN TWO WORDS`）——超一个词就是 0 分
- 数字、拼写必须准确。`week` vs `weeks` 都算错

### Section 4 专项（学术讲座，无对话、不停顿）
- 讲座常见结构是**引入 → 分点论述 → 举例 → 小结**，但并非固定；用 `firstly / another / for example / finally` 等信号词辅助跟踪进度
- 跟丢时**不要回想**，立刻看下一个空的关键词，用它重新咬住音频
- S4 常考：抽象名词、学术术语、专业概念。这些词认识但反应慢 → 靠王陆语料库或听力词汇专练

### 用户实际错题（cam15 T1 S4）
`oil / roads / grass(es) / water / soil / dry / nest(s)` — 全是**简单具体名词**。
这说明不是词汇量问题，是**跟丢了讲座节奏**。所以对策是练 S4 的节奏适应，不是背单词。

## Multiple Choice（当前唯一诊断：10 题对 7 题，70%）

### 核心技巧
- **先读选项，划出选项之间的差异点**——考的就是这个差异
- 音频会把**所有选项都提到**，只有一个是最终答案
- 关键在 `but / actually / no, sorry / on second thought` 这类转折——转折后的才是答案

### 三个高频陷阱
| 陷阱 | 表现 | 破解 |
|------|------|------|
| 说了但否定 | 提到选项 A 但说 "we decided against A" | 听完整句再选 |
| 说了但过时 | "we used to do A, now we do B" | 注意时态 |
| 同义替换 | 选项写 `expensive`，音频说 `beyond our budget` | 熟悉常见替换 |

## Matching（用户 S3 表现最好，4/4）

- 选项通常比题目多，**用不完是正常的**
- 注意题干说明：`You may use any letter more than once` = 同一字母可重复用
- 边听边排除，听到一个划掉一个

---

## Map / Plan Labelling（用户尚未测试，风险未知）

### 核心技巧
- **开始前先定位起点**：`entrance / you are here / reception` 通常是描述起点
- **方位词是命脉**，必须条件反射：
  - `opposite`（正对面）vs `next to`（旁边）vs `beside`（紧邻）
  - `at the far end`（最里头）、`at the back of`（后方）
  - `turn left/right`、`go straight past`（径直经过，**不是进去**）
  - `on your left`（在你左手边）— 注意是**说话人视角**
- 用手指跟着地图走，别只用眼睛

> 地图题技巧推荐看 B站 Cora（作者说这个有用，我未验证）

## Sentence Completion / Short Answer

- 答案通常是**原词**，不是同义替换（和阅读不同）
- 但**题干**一定是同义替换过的
- 注意单复数、时态
