## Task 1：四段式结构（必须严格执行）

| 段落 | 内容 | 关键 |
|------|------|------|
| 1. 开头段 | 改写题目 | 换图表词 + 换动词 + 换关键词，**不能抄题** |
| 2. **概述段** | `Overall,` + 1-2 个最突出的总体趋势 | 通常不写细碎数字；缺少清晰 Overview 往往把 TA 限制在 Band 5 左右，不等于整篇 Overall 必然封顶 5 |
| 3. 主体段1 | 数据组 A：起点 → 变化 → 终点/极值 | 按逻辑分组，不按图表顺序罗列 |
| 4. 主体段2 | 数据组 B + 对比 | 用 `whereas / while / by contrast` 做对比 |

### Overview 是 TR 的生命线
用户 Task 1 已犯：**无 Overview**。这是最贵的错误，也是最好修的——一句话的事。

模板：`Overall, [最大趋势], while [第二突出的特征].`

### 数据取舍
只写：起点、终点、峰值、谷值、最大变化、关键转折点。
**不要逐条罗列所有数字。**

### 绝对禁止
- 分析原因（Task 1 只描述，不解释）
- 发表个人观点
- 双图题只写一个图

## Task 2：结构与立场

### 四段式
1. 开头段：改写题目 + 明确立场
2. 主体段1：论点 A + 解释 + 例子
3. 主体段2：论点 B（或对立面）+ 解释 + 例子
4. 结论段：重申立场，不引入新内容

### 立场可以中立
> 作者原话："大作文写中立立场完全可以。"

不必强行一边倒。`While A has merits, B is more significant` 这种平衡立场只要论证清晰，一样得分。

### 6.0 的达标线（用户目标）
- 回应了题目所有部分
- 有清晰的段落划分
- 论点有解释和例子支撑
- 语法错误不影响理解
- 目标至少 250 词并完整展开论证；字数明显不足通常反映 Task Response 展开不够，不表述成独立的机械扣分

## 练习方法

### 顺序不能反
1. 先自己限时写完
2. **再**看范文/老师思路
3. 对比差异，记录到错误档案

先看范文再写 = 你写的是范文的复制品，练不到自己的思维。

### 题型覆盖式练习（不要随机刷）
小作文每类各 2 篇：

- [ ] 动态线图　- [ ] 静态图　- [ ] 饼图　- [ ] 柱状图
- [ ] 混合图　　- [ ] 地图题　- [ ] 流程图

大作文 7-8 篇，覆盖四类题：同意与否 / 讨论双方 / 问题原因对策 / 利弊。

### 时间分配
Task 1：20 分钟（含 3 分钟读图）｜Task 2：40 分钟（含 5 分钟审题列提纲）
